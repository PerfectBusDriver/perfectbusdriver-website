📋 Politique de Confidentialité

Dernière mise à jour : 18 novembre 2025

🔒 Votre vie privée est notre priorité. Perfect Bus Driver respecte votre vie privée et s'engage à protéger vos données personnelles conformément au Règlement Général sur la Protection des Données (RGPD).

1. Introduction

La présente Politique de Confidentialité explique comment Perfect Bus Driver ("nous", "notre", "l'application") collecte, utilise, stocke et protège vos informations personnelles lorsque vous utilisez notre application mobile.

En utilisant Perfect Bus Driver, vous acceptez les pratiques décrites dans cette politique.

2. Données Collectées

2.1 Données de Localisation GPS

Quand collectons-nous ces données ?

  • UNIQUEMENT lorsque vous démarrez manuellement la fonctionnalité "Traçage de Circuit"
  • Une notification persistante vous informe en temps réel de la collecte active
  • La collecte s'arrête immédiatement lorsque vous arrêtez le traçage

Comment utilisons-nous ces données ?

  • Enregistrement de vos circuits de travail sur votre appareil local
  • Création de fichiers exportables (formats KML, JSON, GPX, CSV)
  • Visualisation de vos trajets sur carte
  • AUCUN envoi vers nos serveurs ou des serveurs tiers

⚠️ Important : Vos données GPS restent exclusivement sur votre appareil. Nous ne collectons, ne stockons et ne transmettons AUCUNE donnée de localisation sur des serveurs externes.

Base légale (RGPD) :

  • Votre consentement explicite (action manuelle de démarrage du traçage)
  • Exécution d'une fonctionnalité que vous avez expressément demandée

2.2 Données de l'Appareil

L'application peut accéder à :

  • Stockage local : Pour sauvegarder vos circuits et paramètres
  • Capteurs : Boussole et accéléromètre pour améliorer la navigation
  • État de la batterie : Pour optimiser la consommation énergétique

2.3 Notifications

L'application envoie des notifications locales pour :

  • Vous informer du traçage GPS actif (notification obligatoire Android)
  • Vous rappeler vos temps de repos (si vous activez cette fonctionnalité)
  • Alertes réglementaires (repos hebdomadaire/quotidien)

Ces notifications sont gérées localement sur votre appareil.

3. Utilisation des Données

Nous utilisons vos données uniquement pour :

  • Fournir les fonctionnalités de traçage GPS et navigation
  • Calculer les statistiques de vos circuits (distance, arrêts)
  • Vous permettre d'exporter vos données dans différents formats
  • Améliorer l'expérience utilisateur de l'application
  • Respecter les obligations légales applicables

✅ Nous ne vendons JAMAIS vos données à des tiers.

✅ Nous ne partageons JAMAIS vos données de localisation.

✅ Nous n'utilisons AUCUN tracker publicitaire.

4. Stockage et Sécurité des Données

4.1 Stockage Local

Toutes vos données sont stockées localement sur votre appareil dans un espace sécurisé :

  • Utilisation du stockage scopé Android (Scoped Storage)
  • Chiffrement des préférences sensibles (EncryptedSharedPreferences)
  • Aucune synchronisation cloud automatique

4.2 Mesures de Sécurité

  • Chiffrement des données sensibles sur l'appareil
  • Permissions Android strictement limitées au nécessaire
  • Code régulièrement audité pour les vulnérabilités
  • Mises à jour de sécurité régulières

4.3 Durée de Conservation

Vos données sont conservées :

  • Circuits enregistrés : Jusqu'à suppression manuelle par vous
  • Préférences : Jusqu'à désinstallation de l'application
  • Données temporaires : Supprimées automatiquement

5. Partage de Données

Perfect Bus Driver ne partage vos données avec AUCUN tiers.

Les seules exceptions sont :

  • Export volontaire : Lorsque vous exportez manuellement un circuit (KML, JSON, etc.)
  • Obligation légale : Si requis par la loi (décision de justice, autorité compétente)

6. Vos Droits (RGPD)

Conformément au RGPD, vous disposez des droits suivants :

6.1 Droit d'Accès

Vous pouvez accéder à toutes vos données directement dans l'application (menu "Mes Circuits").

6.2 Droit de Rectification

Vous pouvez modifier vos circuits enregistrés à tout moment.

6.3 Droit à l'Effacement

Vous pouvez supprimer vos circuits un par un ou tous à la fois.

6.4 Droit de Portabilité

Vous pouvez exporter toutes vos données dans des formats standards (KML, JSON, GPX, CSV).

6.5 Droit d'Opposition

Vous pouvez retirer votre consentement à tout moment en :

  • Arrêtant le traçage GPS
  • Révoquant les permissions dans les paramètres Android
  • Désinstallant l'application

💡 Comment exercer vos droits : Toutes ces actions peuvent être effectuées directement dans l'application ou via les paramètres Android. Pour toute question, contactez-nous à perfectbusdriver@gmail.com

7. Services Tiers

7.1 OpenStreetMap

L'application utilise OpenStreetMap pour afficher les cartes :

  • Service gratuit et open-source
  • Consulter leur politique : OSM Privacy Policy

7.2 OSRM (Open Source Routing Machine)

Pour le calcul d'itinéraires :

  • Service de routage open-source
  • Aucune donnée personnelle transmise

8. Protection des Mineurs

Perfect Bus Driver est destinée aux conducteurs professionnels majeurs. Nous ne collectons pas sciemment de données concernant des mineurs de moins de 18 ans.

9. Modifications de cette Politique

Nous pouvons mettre à jour cette Politique de Confidentialité occasionnellement. Nous vous informerons de tout changement significatif via :

  • Une notification dans l'application
  • Mise à jour de la date en haut de ce document

Nous vous encourageons à consulter régulièrement cette page.

10. Conformité Légale

Cette politique est conforme aux réglementations suivantes :

  • RGPD (Règlement Général sur la Protection des Données - UE)
  • Loi Informatique et Libertés (France)
  • Google Play Store Policies
  • Android Permissions Best Practices
